## Honest gaps / not run in this environment

- **No live browser render**: the chamber GUI in this container is the official
  dsh web frontend with cookie auth and no browser binary available; render
  evidence = bundle-in-boot-graph + jsdom render tests. A real
  `Settings → MCP 服务器` click-through needs a browser/desktop session.
- **No live model-request tool capture**: rc.1 sessions stay cold until a UI
  surface claims them; no headless HTTP/WS path found that starts the agent loop
  (prompts queue but no LLM request fires — see `docs/ui-notes.md`/M0 gaps).
  Scope gating rests on the real-registry in-process suite + the live supervisor
  evidence.
- First boot right after `dsh plugin add` can miss the client roster (module
  scan race); restart fixes it — documented install step.
